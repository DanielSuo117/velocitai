Rules

严格规则，每条配反例 + 正例

Rules 是强制约束（Must / Must-not），确保 Agent 生成的代码符合项目规范。每条规则都包含 ❌ 反例和 ✅ 正例。

🎯

定位符策略

  • 六级优先级：P0 ARIA role → P5 相对 XPath
  • 禁止哈希类名（sc-xxx / css-xxx）
  • 禁止绝对 XPath
  • 状态类 selector 必须配 text 锁定
  • text= 子串匹配的精确化处理
⏳

超时 & 等待

  • 超时先排查页面，再查定位符
  • SPA 切换后 networkidle ≠ 渲染完成
  • 全局隐式等待 + 仅慢路径显式 timeout
  • 禁止 time.sleep()
🧪

断言模式

  • 页面对象不包含断言（is_page_loaded 除外）
  • 禁止无效断言（assert True）
  • 列表搜索结果要验证内容不只验证数量
  • Toast/弹窗需带文本精确匹配
🌐

浏览器上下文

  • 禁止 session 级共享 context（跨域 cookie 污染）
  • 同域 class 级共享需满足三个条件
  • 认证通过 URL token 独立执行
  • 不手动管理浏览器生命周期
📑

编码规范

  • 类 PascalCase / 方法 snake_case / 常量 UPPER_SNAKE
  • 定位符声明为类常量，行尾标注级别
  • 导入顺序：标准库 → 第三方 → 项目内
  • 新页面必须同步导出到 __init__.py
🛡

Agent 行为边界

  • 运行测试前必须确认 --env 参数
  • Git 操作（commit/push）需用户授权
  • 禁止自行默认环境或无声纠偏
  • 文档与代码冲突时必须询问
📊

报告策略

  • 仅失败时生成 HTML 报告
  • 全绿跳过报告生成，避免堆积
  • 标记变量覆盖全阶段（含 teardown）
  • 域名统计无论通过与否都输出
📏

Performance API 隔离

  • 收集后立即 clearResourceTimings()
  • 清空必须在同一次 evaluate 内部
  • class 级共享 context 是高危场景
  • 单独通过 + 批量失败 → 首查此项
Best Practices

每条规则都有 ❌ 反例 和 ✅ 正例

不只是抽象原则 —— 每条规则都给出具体的代码示例，让 Agent 和开发者都能直接对照执行。

locator_bad.py
❌ 反例 
# 哈希类名 — 每次构建都会变化
SUBMIT_BTN = "css=.sc-bdVaJa.dKPpRt"

# 绝对 XPath — 任何 DOM 改动都会断
NAME_INPUT = "/html/body/div[1]/div[2]/input"

# text= 子串匹配 — 命中「收起筛选」
FILTER_BTN = "text=筛选"
locator_good.py
✅ 正例 
# P0: ARIA role — 语义稳定
SUBMIT_BTN = "role=button[name='提交']"

# P2: data-testid — 专为测试设计
NAME_INPUT = "[data-testid='name-input']"

# 精确匹配 — 不命中「收起筛选」
FILTER_BTN = 'text="筛选"'
Workflow

Agent 工作流：从需求到测试用例

Agent 按照 Skills 路由表自动编排任务，从分析页面到生成测试、运行验证、沉淀经验。

1

探索目标页面

使用 agent-browser 获取页面 DOM 快照，分析元素结构和可用的定位策略。节省 82–93% 的 token 消耗。

2

生成 Page Object

调用 gen-page-test Skill，自动生成 PageObject 类，包含定位符常量（标注 P0–P5）、操作方法和 is_page_loaded()。

3

编写测试用例

基于 add-regression-point 和 case-round-trip Skills 生成回归测试，确保用例往返闭合、状态一致。

4

运行 & 调试

通过 test-runner 执行测试，失败时 quick-debug 自动按三步法排查：确认页面 → 检查 tab → 查定位符。

5

代码审查

code-reviewer 代理按 P0/P1/P2 分级审查，结合 AST 知识图谱分析变更影响半径和测试覆盖率。

6

沉淀经验

踩坑后自动将经验写入 Skills / Rules / Docs —— Agent 的「肌肉记忆」持续进化，同类问题不再复现。

Self-Evolution

自我进化机制（P0 最高优先级）

Agent 在踩坑、被纠正、或发现重复问题时，自动将经验沉淀到项目知识库。

Quick Start

三步开始使用

将 Harness 复制到你的 Playwright + pytest 项目，配置环境，即可开始用 Agent 驱动测试。 

# 1. 复制 Harness 到你的项目
$ cp -r .claude/ CLAUDE.md docs/  /path/to/your-project/

# 2. 安装依赖 & 浏览器
$ python -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt
$ playwright install chromium

# 3. 运行测试（--env 必须指定）
$ pytest tests/ --env=pre

# 查看报告
$ allure serve reports/allure-results
