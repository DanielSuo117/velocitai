问题所在The Problem

AI Agent 写测试，为什么总是不靠谱？Why Do AI Agents Always Write Unreliable Tests?

没有治理体系的 AI Agent 就像没有规范的新人实习——能写代码，但写出来的测试脆弱、不稳定、无法维护。 An AI Agent without a governance system is like an untrained intern — it can write code, but the tests it produces are brittle, unstable, and unmaintainable.

✕ 裸 Agent（无治理）Bare Agent (No Governance)

  • 使用绝对 XPath、哈希类名等脆弱定位符Uses fragile locators like absolute XPath and hash class names
  • 随意 time.sleep()，超时后盲目加秒Randomly inserts time.sleep(), blindly adds seconds on timeout
  • 写出 assert True、assert len(x) > 0 等无效断言Writes useless assertions like assert True or assert len(x) > 0
  • 不理解 SPA 路由切换、新 tab 上下文Doesn't understand SPA route changes or new tab context
  • 同样的错误反复出现，没有记忆Repeats the same mistakes with no memory
  • 跨域 cookie 污染导致批量失败Cross-domain cookie pollution causes batch failures
→

✓ VelocitAI 治理后With VelocitAI Governance

  • 六级定位符优先级，P0 ARIA role 优先Six-tier locator priority, P0 ARIA role first
  • 隐式等待为主，仅慢路径用显式 timeoutImplicit wait by default, explicit timeout only for slow paths
  • 断言必须验证具体内容和状态Assertions must verify specific content and state
  • 内置新 tab 检测、SPA 渲染等待规则Built-in new tab detection and SPA render wait rules
  • 踩坑后自动沉淀到 Skills/Rules，永不复犯Lessons learned auto-saved to Skills/Rules, never repeated
  • context 隔离策略，消除跨域污染Context isolation strategy eliminates cross-domain pollution

定位符策略Locator Strategy

  • 六级优先级：P0 ARIA role → P5 相对 XPathSix-tier priority: P0 ARIA role → P5 relative XPath
  • 禁止哈希类名（sc-xxx / css-xxx）Hash class names prohibited (sc-xxx / css-xxx)
  • 禁止绝对 XPathAbsolute XPath prohibited
  • 状态类 selector 必须配 text 锁定State-based selectors must be locked with text
  • text= 子串匹配必须精确化处理text= substring matching must be handled with precision
⏳

超时 & 等待Timeout & Wait

  • 超时先排查页面 URL，再查定位符On timeout, check page URL first, then check locator
  • SPA 切换后 networkidle ≠ 渲染完成After SPA transition, networkidle ≠ render complete
  • 全局隐式等待 + 仅慢路径显式 timeoutGlobal implicit wait + explicit timeout only for slow paths
  • 禁止 time.sleep()，使用 Playwright 原生等待time.sleep() prohibited; use Playwright native waits
🧪

断言模式Assertion Patterns

  • 页面对象不包含断言（is_page_loaded 除外）Page objects must not contain assertions (except is_page_loaded)
  • 禁止无效断言（assert True）Trivial assertions prohibited (assert True)
  • 列表搜索结果要验证内容不只验证数量Search results must verify content, not just count
  • Toast/弹窗需带文本精确匹配Toast/dialog must use exact text matching
🌐

浏览器上下文Browser Context

  • 禁止 session 级共享 context（跨域 cookie 污染）Session-level shared context prohibited (cross-domain cookie pollution)
  • 同域 class 级共享需满足三个条件Same-domain class-level sharing requires three conditions
  • 认证通过 URL token 独立执行Auth via URL token executed independently
  • 不手动管理浏览器生命周期Do not manually manage browser lifecycle
📑

编码规范Coding Conventions

  • 类 PascalCase / 方法 snake_case / 常量 UPPER_SNAKEClass PascalCase / method snake_case / constant UPPER_SNAKE
  • 定位符声明为类常量，行尾标注级别Locators declared as class constants with priority level annotation
  • 导入顺序：标准库 → 第三方 → 项目内Import order: stdlib → third-party → project
  • 新页面必须同步导出到 __init__.pyNew pages must be simultaneously exported to __init__.py

  • 运行测试前必须确认 --env 参数Must confirm --env parameter before running tests
  • Git 操作（commit/push）需用户授权Git operations (commit/push) require user authorization

报告策略Report Strategy

  • 仅失败时生成 HTML 报告，全绿跳过Generate HTML report only on failure; skip if all green
  • 标记变量覆盖全阶段（含 teardown）Marker variables cover all phases (including teardown)
  • 域名统计无论通过与否都输出Domain stats output regardless of pass/fail
