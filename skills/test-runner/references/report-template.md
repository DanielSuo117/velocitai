# 测试运行摘要模板

> 由 [test-runner](../SKILL.md) 按需加载。需要向用户汇报运行结果时再读。

运行完成后，按以下格式输出摘要：

```
## 测试运行摘要

**运行模式：** 单个 story / 主流程全量
**环境：** pre / prod
**时间：** 2026-04-15 15:30

### 结果

| 状态 | 数量 |
|------|------|
| PASSED | X |
| FAILED | X |
| ERROR | X |
| SKIPPED | X |

### 失败详情（如有）

| 测试用例 | 失败类型 | 原因 | 建议操作 |
|----------|---------|------|---------|
| test_xxx | A: 定位符失效 | text=xxx 不唯一 | 使用 locator-replacer |
| test_yyy | D: 认证失败 | token 过期 | 更新 settings.py |
```
