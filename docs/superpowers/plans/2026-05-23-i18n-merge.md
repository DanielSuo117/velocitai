# 中英文页面合并为单文件 i18n 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `index.html`（中文）和 `en/index.html`（英文）合并为根目录下的单个 `index.html`，通过 JavaScript 实现客户端语言切换，无需页面跳转。

**Architecture:** 使用 `html[lang]` 属性 + `[data-lang]` 标记双语内容，CSS 控制显示/隐藏，JS 切换 lang 属性并持久化到 localStorage。所有文本元素内嵌 `<span data-lang="zh">` 和 `<span data-lang="en">` 两个版本。代码块 `<pre>` 整体用 `<div data-lang>` 包裹。

**Tech Stack:** 纯 HTML/CSS/JS，无构建工具依赖。

- [ ] **Step 3: 在 `<script>` 块开头添加 switchLang 函数和初始化**

```javascript
// ─── I18N LANGUAGE SWITCH ───
function switchLang(lang) {
  const htmlLang = lang === 'en' ? 'en' : 'zh-CN';
  document.documentElement.lang = htmlLang;
  localStorage.setItem('velocitai-lang', lang);

  // Update active button
  document.getElementById('langZh').classList.toggle('active', lang === 'zh');
  document.getElementById('langEn').classList.toggle('active', lang === 'en');

  // Update title and meta
  const titles = { zh: 'VelocitAI — AI 驱动的 UI 自动化 Agent Harness', en: 'VelocitAI — AI-Driven UI Automation Agent Harness' };
  const descs = { zh: 'VelocitAI 是一套通用 UI 自动化 Agent Harness，为 AI Agent 提供完整的 Skills、Rules 和自我进化机制，驱动企业级 UI 回归测试。', en: 'VelocitAI is a universal UI automation Agent Harness providing AI Agents with complete Skills, Rules, and self-evolution mechanisms to drive enterprise-grade UI regression testing.' };
  document.title = titles[lang];
  document.querySelector('meta[name="description"]').content = descs[lang];
  document.querySelector('meta[property="og:title"]').content = titles[lang];
  document.querySelector('meta[property="og:description"]').content = lang === 'zh'
    ? '用 AI Agent 驱动 UI 自动化测试。13 个 Skills + 14 个 Rule 文件，4 倍编码提效，从生成到审查全自动化。'
    : 'Drive UI automation testing with AI Agents. 13 Skills + 14 Rule files, 4x coding efficiency, fully automated from generation to review.';

  // Restart typewriter
  restartTypewriter(lang);
}

// Init language on page load
(function() {
  const saved = localStorage.getItem('velocitai-lang') || 'zh';
  if (saved === 'en') switchLang('en');
})();
```

- [ ] **Step 4: 修改 typewriter 代码，支持语言切换时重启**

将原 typewriter IIFE 改为可重启的函数：

```javascript
// ─── TYPEWRITER EFFECT ───
let typewriterInterval = null;
function restartTypewriter(lang) {
  const target = document.getElementById('typewriterTarget');
  if (!target) return;
  if (typewriterInterval) clearInterval(typewriterInterval);

  const texts = { zh: 'UI 自动化测试引擎', en: 'UI Automation Test Engine' };
  const text = texts[lang || 'zh'];
  target.textContent = '';
  const cursor = document.createElement('span');
  cursor.className = 'typewriter-cursor';
  cursor.setAttribute('aria-hidden', 'true');
  target.appendChild(cursor);

  let i = 0;
  typewriterInterval = setInterval(() => {
    if (i < text.length) {
      target.insertBefore(document.createTextNode(text[i]), cursor);
      i++;
    } else {
      clearInterval(typewriterInterval);
      typewriterInterval = null;
    }
  }, 80);
}

// Initial typewriter (delayed for hero animation)
setTimeout(() => {
  const lang = localStorage.getItem('velocitai-lang') || 'zh';
  restartTypewriter(lang);
}, 600);
```
